# MyNotes 

一个简单的 Android 笔记应用，专注于轻量与易用。

## 功能特性
- 创建,编辑,删除笔记
- 轻量设计,无多余权限申请
- 使用jetpack compose开发,完美兼容安卓深色模式和动态色彩
- 富文本编辑以html格式存储,扩展性强
- 分享优化了对于图片和文本的分享,可选择单独分享文本或图片
- 笔记保存为本地数据库实现,也可对接服务器实现云端同步
- 纯 Kotlin 实现,代码简洁易读

##  技术栈
- **语言**: Kotlin
- **构建工具**: Gradle Kotlin DSL
- **平台**: Android

## 快速开始

### 环境要求
- Android SDK API 36 (编译版本)
- Gradle 9.1.0
- AGP 9.1.1
- kotlin 2.2.10
